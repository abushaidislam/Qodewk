## The Token Pricing Multi-Tier Reality

In early 2024, calculating an LLM API bill was straightforward multiplication:

```text
Total = (N_in * P_in) + (N_out * P_out)
```

Today, autonomous coding agents rely heavily on **prompt caching**. When Claude Code or Cursor sends a 150,000-token codebase context window repeatedly, Anthropic discounts cached input tokens by **90%** ($0.30 per million instead of $3.00), while assessing a **25% premium** ($3.75 per million) for writing that cache.

If your telemetry engine ignores prompt caching, your cost calculations will be off by up to **800%**.

## Deterministic Cost Calculation Algorithm

To prevent floating point precision drift, Qodewk calculates dollar values down to 6 decimal places before rounding:

```typescript
export function computeCost(
  usage: TokenUsage,
  card: ModelRateCard
): number {
  const inputCost = ((usage.inputTokens ?? 0) / 1_000_000) * card.inputPerMillion;
  const outputCost = ((usage.outputTokens ?? 0) / 1_000_000) * card.outputPerMillion;
  
  const cacheReadCost = card.cacheReadPerMillion
    ? ((usage.cacheReadTokens ?? 0) / 1_000_000) * card.cacheReadPerMillion
    : 0;

  const cacheWriteCost = card.cacheWriteWritePerMillion
    ? ((usage.cacheWriteTokens ?? 0) / 1_000_000) * card.cacheWritePerMillion
    : 0;

  return Math.round((inputCost + outputCost + cacheReadCost + cacheWriteCost) * 1_000_000) / 1_000_000;
}
```

## Offline-First with 24-Hour Remote Sync

AI providers constantly tweak their prices. To ensure developers get up-to-date rate cards without breaking offline mode, Qodewk uses a dual strategy:

1. **Embedded Zero-Native Bundles:** `@qodewk/pricing` includes hardcoded rate cards that require zero network requests, ensuring instant CLI responsiveness (under 2ms).
2. **Dynamic 24h Background TTL:** When internet access is present, the CLI non-blockingly pulls updated rate cards from `https://qodewk.dev/api/pricing/sync` and stores them in `~/.qodewk/pricing-cache.json`.
3. **Airplane Mode Immunity:** If you code on a flight with no Wi-Fi, Qodewk gracefully operates on the cached or embedded rates without stalling or raising network errors.
