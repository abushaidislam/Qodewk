<TLDR>
Developers are exhausted by sterile SaaS dashboards with generic blue gradients. Qodewk embraces physical thermal receipts—tactile zig-zag cut edges, warm cream paper tones, monospace tabular data, and scannable barcodes.
</TLDR>

## The Anti-SaaS Aesthetic

Modern developer tooling has converged on a tired monoculture: dark slate backgrounds (`#0f172a`), neon purple button glows, generic sans-serif fonts, and cards with identical rounded corners.

When we set out to design Qodewk, we asked ourselves a simple question:

> *What is the universal, physical artifact that represents an honest, verified transaction?*

The answer was right on our desks: **the paper thermal cash register receipt**.

Thermal receipts are brutally functional yet inherently charming. They are monospace by necessity, structured with ASCII line dividers, stamped with timestamps, and cut from rolls of paper with serrated blades.

---

## The Claude Warm Editorial Palette

Rather than stark clinical white (`#ffffff`) or cool bluish gray (`#f8fafc`), Qodewk's design system is grounded in the **Claude Warm Editorial** palette:

- **Canvas (`#faf9f5`):** A warm, parchment-tinted cream reminiscent of premium print paper.
- **Card Surface (`#efe9de`):** A soft, tactile surface that separates foreground receipts from the backdrop.
- **Dark Surface (`#181715`):** Deep obsidian for code terminal chrome and dark mode contrast.
- **Warm Coral Accent (`#cc785c`):** Signature warm terracotta action tone.
- **Ink (`#141413`):** Deep charcoal ink, softer on human eyes than pure black `#000000`.

```css
:root {
  --canvas: #faf9f5;
  --surface-card: #efe9de;
  --surface-dark: #181715;
  --primary-coral: #cc785c;
  --hairline: #e6dfd8;
  --ink: #141413;
}
```

## Crafting the Serrated Jagged Edge in SVG

A thermal receipt isn't complete without the iconic perforated tear at the top and bottom. Standard CSS border radius cannot create jagged teeth. Instead, we built dynamic SVG sawtooth masks:

```tsx
export function SerratedEdge({ orientation }: { orientation: "top" | "bottom" }) {
  // 24 triangular teeth across the card width
  const teeth = Array.from({ length: 24 }).map((_, i) => {
    const x = i * 16;
    return `${x},0 ${x + 8},8 ${x + 16},0`;
  }).join(" ");

  return (
    <div className={`overflow-hidden h-2 w-full text-card ${orientation === "bottom" ? "rotate-180" : ""}`}>
      <svg viewBox="0 0 384 8" className="w-full h-full fill-current">
        <polygon points={`0,0 ${teeth} 384,0 384,8 0,8`} />
      </svg>
    </div>
  );
}
```

By coloring the SVG polygon with `text-card` (`currentColor`), the teeth seamlessly blend into whichever background card or modal container holds the receipt, completely eliminating unsightly white triangle artifacts in dark mode.

## Code 128 Monospace Barcodes

Every receipt card features a high-contrast Code 128 vector barcode rendered at the bottom. 

The barcode is not just visual ornamentation—it encodes the canonical receipt identifier (e.g., `rec_9f8210ac`). When scanned with a smartphone camera or handheld barcode reader, it resolves directly to the immutable verification URL at `https://qodewk.dev/r/[id]`.

```text
 ║█║▌║█║▌│║▌█║▌║║█║▌║█║▌│║▌█║▌║
       rec_9f8210ac74b12
```

## Typography Hierarchy: Display Serif Meets JetBrains Mono

To reinforce the editorial craftsmanship:
1. **Headlines:** Set in `Copernicus` or `Cormorant Garamond` (weight 400, tight tracking `-0.8px`).
2. **Body & Interface:** Clean humanist typography (`StyreneB` or `Inter`).
3. **Receipt Data:** `JetBrains Mono` with `font-variant-numeric: tabular-nums` to guarantee vertical number alignment across token quantities, costs, and percentage metrics.

The result is a design that respects the developer's intelligence—evoking tactile physical craft while delivering precision telemetry.
