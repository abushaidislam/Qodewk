## The Governance Vacuum in Autonomous Engineering

Enterprises are rapidly adopting AI coding agents. However, VP of Engineering and CFO discussions frequently stall on three key risks:

1. **Runaway API Budgets:** A single rogue looping agent can burn through hundreds of dollars in Claude 3.7 or o1 reasoning tokens on a single task.
2. **Attribution Opacity:** When bugs reach staging, teams struggle to determine whether a line was authored by a human developer or generated by an autonomous subagent.
3. **Compliance Audit Trails:** Regulated industries require immutable records demonstrating what tools interacted with the codebase during each release cycle.

## Sticky PR Comments via Composite GitHub Action

In `packages/action`, we created the official Qodewk GitHub Action. It integrates directly into standard CI/CD workflows:

```yaml
name: Qodewk Agent Telemetry
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  telemetry:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: abushaidislam/qodewk-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          max-pr-cost: "15.00" # Budget guard threshold
```

When triggered, the action parses all commits in the pull request branch, retrieves the corresponding `refs/notes/qodewk` receipts, and posts a **sticky markdown comment** on the PR discussion:

```markdown
### 🧾 Qodewk Pull Request Receipt

| Metric | Measured Value | Provenance |
| :--- | :--- | :--- |
| **Commits Analyzed** | 4 commits | verified |
| **AI-Written Ratio** | 88.5% | observed |
| **Primary Agent** | Claude Code (claude-3-7-sonnet) | observed |
| **Input Tokens** | 148,210 (cache hit: 84%) | observed |
| **Output Tokens** | 12,400 | observed |
| **Total Incurred Cost** | **$0.4820 USD** | verified |

> [✓] Source code was never uploaded to Qodewk.  
> [View interactive thermal receipt →](https://qodewk.dev/r/rec_pr_98410a)
```

If another commit is pushed to the PR branch, the action seamlessly updates the existing comment rather than spamming the discussion thread with duplicate messages.

## Hard Budget Guards in CI

If a developer accidentally leaves an agent running in an infinite re-try loop and generates a pull request with an estimated cost exceeding the configured threshold (e.g., `--max-pr-cost=15.00`), the action fails the CI check with an informative error:

```text
Error: PR AI token cost ($18.42 USD) exceeds budget limit ($15.00 USD).
Action: Review agent logs or request lead override.
```

This prevents unexpected billing surprises before changes are merged into the main branch.

## SOC 2 and Compliance Readiness

Because Qodewk never transmits raw source code or diff hunks, enterprise security teams can deploy it across internal repositories without requiring new data processing agreements (DPAs) or exposing confidential business logic.
