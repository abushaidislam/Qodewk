---

Get up and running with **Qodewk** in seconds. Follow these steps to configure autonomous Git telemetry, install background hooks, and generate your first digital receipt.

<Steps>
  <Step>
    ### Install the CLI

    Install Qodewk globally or execute it directly with `npx`:

    ```bash
    # Install globally
    npm install -g qodewk

    # Or run directly with npx
    npx qodewk --help
    ```

    <Callout type="info">
      Node.js 20 or higher is required. Qodewk runs on macOS, Linux, and Windows.
    </Callout>
  </Step>

  <Step>
    ### Install Git Hooks (< 5ms Non-Blocking)

    Install the non-blocking post-commit and post-rewrite Git hooks into your local repository:

    ```bash
    qodewk hook install
    ```

    <Callout type="info">
      **Zero Pipeline Blocking:**  
      Qodewk hooks spawn background processes detached from standard I/O streams and exit with code `0` in less than 5ms. They coexist non-destructively with Husky and Lefthook using safe comment boundaries.
    </Callout>

    You can check hook status or verify configuration at any time:

    ```bash
    qodewk hook status
    ```
  </Step>

  <Step>
    ### Configure Telemetry & Rate Cards

    Qodewk works out of the box with zero configuration using embedded SQLite and built-in rate cards. To customize provider detection or salt keys, add configuration to your `.env` or project root:

    ```txt title=".env"
    # Optional: Custom salt for HMAC-SHA256 anonymized repository hashes
    QODEWK_SALT=your_custom_salt_value_here

    # Optional: Confidence threshold floor (0.0 to 1.0)
    QODEWK_CONFIDENCE_FLOOR=0.85
    ```

    You can also provide a declarative configuration file `qodewk.config.ts`:

    ```ts title="qodewk.config.ts"
    import { defineConfig } from "@qodewk/core";

    export default defineConfig({
      privacy: "strict", // Zero raw diff exfiltration
      telemetry: {
        harvesters: ["claude", "cursor", "codex", "windsurf", "antigravity"],
        gitNotesRef: "refs/notes/qodewk",
      },
      rateCards: "latest",
    });
    ```
  </Step>

  <Step>
    ### Verify Telemetry with Dry Run

    Run a dry-run audit on your current working tree to inspect detected agent footprints, line mutations, and token cost estimations:

    ```bash
    qodewk --dry-run
    ```

    You will see the detected provider sessions and calculated confidence score without writing any data to disk.
  </Step>

  <Step>
    ### Generate Your First Receipt

    Generate a local monospace thermal receipt for your latest commit:

    ```bash
    qodewk
    ```

    To export as machine-readable JSON:

    ```bash
    qodewk --json
    ```

    To publish a public verifiable receipt link:

    ```bash
    qodewk share
    ```

    <Callout>
      **Privacy Guarantee:**  
      Source code and file contents are **never** uploaded. The public receipt includes only mutation metrics, token counts, cost heuristics, and salted cryptographic hashes.
    </Callout>
  </Step>
</Steps>
