Qodewk operates seamlessly across local development, terminal workflows, and automated CI/CD pipelines.

## 1. Terminal Monospace Receipts

Running `qodewk` without arguments inspects your current repository, determines the primary AI coding agent session, and prints an authentic monospace thermal receipt directly to your terminal:

```bash
qodewk
```

## 2. Machine-Readable JSON Export

To integrate Qodewk into scripts, metrics dashboards, or custom tooling, use `--json`:

```bash
qodewk --json
```

## 3. Sharing Public Receipts

When you want to showcase digital proof of shipment or share attribution with collaborators:

```bash
qodewk share
```

What happens under the hood:
1. Qodewk sanitizes all local file paths and absolute disk directories.
2. The payload is validated against strict privacy invariants (< 50 KB ceiling).
3. The cryptographic receipt metadata is transmitted to the public registry.
4. You receive a verifiable URL and claim token:

```bash
✓ Receipt published!
URL: https://qodewk.dev/r/rec_01J8Y29K4Z00ABC123DEF456
Author Claim Token: qtk_sec_7a8b9c...
```

## 4. Local Git Notes Storage

By default, Qodewk persists receipts into Git's native object database using Git Notes under `refs/notes/qodewk`:

```bash
# View the note attached to HEAD
git notes --ref=qodewk show HEAD

# List all Qodewk notes
git notes --ref=qodewk list
```

Because notes are part of Git, they travel with your repository when pushed (`git push origin refs/notes/qodewk`) without polluting commit messages or branch history.
