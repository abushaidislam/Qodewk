**Qodewk** is an open-source, universal telemetry and digital receipt generator built for the AI coding agent era.

The Git revision graph and local filesystem constitute the single source of truth across all coding agents. Qodewk extracts mutations from your repository, harvests provider telemetry (Claude Code, Cursor, Codex, Windsurf, Aider, Antigravity), computes dual-engine token and cost estimations, and generates verifiable digital receipts.

> **Prime Directive:**  
> *"Git tells Qodewk what changed. Provider telemetry, when available, tells Qodewk what was consumed. Qodewk must never present an inference as exact usage."*

## Invariant Engineering Principles

1. **Never Fake Precision:**
   All metrics are explicitly labeled by provenance (`observed`, `estimated`, `imported`, `verified`, or `unknown`). Costs always include confidence bounds.

2. **Privacy by Construction:**
   Raw source code and diff hunks **never** leave your machine. Public receipts transmit only file counts, line mutations, language ratios, token counts, and HMAC-SHA256 salted hashes under a strict **50 KB** payload cap.

3. **Git Hooks Under 5ms:**
   Hooks (`post-commit`, `post-rewrite`) spawn background processes detached from standard streams and exit immediately, coexisting cleanly with Husky and Lefthook.

4. **100% Offline & Local First:**
   Generate terminal thermal receipts and persist to SQLite (`~/.qodewk/state.db`) and Git Notes (`refs/notes/qodewk`) without needing internet connectivity or a cloud account.
