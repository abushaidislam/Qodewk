Qodewk uses a versioned multi-model rate card registry to compute accurate dollar costs for AI coding agent sessions.

## Rate Card Registry (`@qodewk/pricing`)

The rate card registry provides granular per-million token pricing across all supported model families:

```ts
import { computeCost, getRateCard } from "@qodewk/pricing";

const card = getRateCard("claude-3-5-sonnet-20241022");

const cost = computeCost("claude-3-5-sonnet-20241022", {
  inputTokens: 15_000,
  outputTokens: 2_500,
  cacheReadTokens: 10_000,
  cacheWriteTokens: 5_000,
});
```

## Provenance & Confidence Calculation

In accordance with Qodewk's prime directive, heuristic calculations must **never** be presented as exact consumption. Costs are tagged with explicit provenance:

* **`observed`**: Direct token consumption parsed from local provider session transcripts (Cursor SQLite, Claude Code JSONL).
* **`estimated`**: AST complexity heuristic fallback based on language token density and net diff lines.
* **`imported`**: Verified external metadata supplied via trusted CI/CD environments.

## API Rate Limiting

The public digital receipt registry (`/api/receipts`) enforces a sliding window rate limiter to prevent abuse and protect infrastructure:

* **Window:** 60 seconds
* **Max Submissions:** 30 requests per IP
* **Max Payload Size:** Strict **50 KB** cap (requests exceeding 50 KB are rejected with HTTP `413 Payload Too Large`).
